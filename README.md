# Coin Flipper

A one‑file Python utility that flips a virtual coin.

## Usage

```sh
python flip.py          # flip once
python flip.py 5        # flip five times
python flip.py -h       # show help
```

## Output

The script prints each flip (`H` for heads, `T` for tails) and a summary of totals and percentages.

## Why?

Great for quick demos, teaching randomness, or just making decisions.
